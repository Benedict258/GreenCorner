Waste2Light Store: static HTML export

- Each file is a standalone page (open it in any browser). CSS is inside each file, using the shared custom properties on :root. Fonts load from Google Fonts.
- index.html is the home page. Links between pages use these file names.
- Files ending in M.html are the 360px phone views.
- SiteHeader, SiteFooter, AdminSidebar, AdminTopbar are the shared parts shown on their own.
- Admin pages (Admin*.html) are staff-only and are the only ones that mention Microscale and margins.
- Photos are placeholders. Customer names, orders and phone numbers are made up.
